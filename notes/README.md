## 更新方式

仓库维护者可以从项目根目录运行：

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe -m bili_notes `
  --export-existing `
  --export-root ".\notes"
```

导出器只复制正文选中的截图，并会把 B 站来源链接规范化为无追踪参数的公开地址。提交前仍需检查新增正文与画面是否适合公开。
