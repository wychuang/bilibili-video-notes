## 怎样开始

打开脉络图，可以先走“弄清 AI 怎么工作 → 说清要解决的问题 → 判断做得好不好”这条主线，也可以直接选择感兴趣的路线。全屏空间中，绿色连线把共同起点、主题分支和具体视频连起来；靠近分支后会展开更多封面。点击视频卡片，在详情中打开完整笔记。

滚轮默认沿当前路线前进或后退。拖动地图会进入自由探索，此时滚轮用于缩放；点击“自由探索”可回到路线。右侧按钮支持缩放、调整视角和返回全景，右上角可进入浏览器全屏。方向键切换路线节点，Home 回到全景，按 `/` 搜索。搜索和“全部内容”可以直接找到任意视频。

全部笔记页提供封面卡片、搜索与筛选，也保留原有六篇起步路线。两个视图使用同一份已读记录。动态效果可以暂停，并遵循系统的减少动态效果设置。手机使用紧凑路线导航和底部详情；不支持 WebGL 的浏览器可用平面视图继续探索。

首页另有 [HackerTube 分类入口](https://hackertube.org/categories) 和 7 条基础课程，涵盖神经网络、Transformer、大模型、软件设计、产品判断、学习方法与统计推理。这些入口也放在相应分支中，标为“外部课程”；目前可前往观看，尚无本站讲解笔记。

每篇保留视频播放区、章节目录、总结提炼和复习内容。点击播放按钮、正文时间戳或图注时间，会联网加载对应视频或分集；若嵌入播放受登录或平台限制，可用播放器下方的链接前往 B 站。截图点击放大，公式可以离线阅读。

页面、封面、截图和字体随仓库提供，下载后可以直接打开本目录的 `flow.html` 或 `index.html`。正文阅读无需安装软件。浏览器对本地文件的进度保存策略可能不同，跨设备以导出文件为准。

## 换设备继续学习

“学过”记录保存在当前浏览器。首页底部可导出进度文件，到另一台设备导入；导入会合并原有记录。没有账户、后台或自动同步，不上传练习答案与阅读记录。
