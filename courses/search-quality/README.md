# 搜索与 Agent 质量：从问题到证据

[打开课程](https://wychuang.github.io/bilibili-video-notes/courses/search-quality/) · [本地入口](index.html)

一条围绕搜索回答、评测、数据与 Agent 的学习路线，补充产品、调研和表达能力。共选入 54 个视频或合集项目：51 篇可读笔记，其中 42 篇新整理、9 篇复用已公开的学习稿；3 条原始证据待补，目录明确标注，暂不生成摘要。整理日期：2026-09-22。

## 怎样开始

打开首页，从“先走通这六步”开始。每次只读一篇，再完成末尾的小练习；其余内容可以搜索，或按核心、补充、拓展筛选。学习目标是能分析一个真实问题、给出证据和验证办法，无需一次读完目录。

文章保留时间戳；点击会联网打开原视频或对应分集。截图可以放大，公式使用离线 MathML。页面和字体均随仓库提供，下载仓库后可直接打开 `index.html`，无需安装软件。浏览器对 `file://` 下的进度保存策略可能不同，跨设备以导出文件为准。

“学过”记录仅保存在当前浏览器。首页底部可导出 JSON，到另一台设备导入；导入会合并既有记录。课程没有账户、后台或自动同步，不上传阅读进度与练习答案。

## 内容与证据边界

- 新稿依据核对过身份与时长的字幕或自动转写；自动识别仍可能出现术语、数字与断句错误。
- 长合集按分集组织。其中 Agent 记忆上传实际包含两门课程，笔记中分别说明覆盖范围。
- 关键原帧经过逐张查看，再与相邻论点匹配；没有有用画面的内容保持文字，不用装饰图冒充视频证据。
- 原视频主张、个人经验、商业宣传、补充判断与迁移练习分别标注；旧版界面和技术限制保留时间背景。
- 这是自主学习材料，不代表原作者认可，也不构成任何公司的官方面试题库、招聘承诺或专业医疗建议。
- 引用与少量截图用于解释、评论和比较，版权归原作者；不提供原视频和完整逐字稿镜像。如有权利问题，可通过仓库 Issue 联系维护者处理。

以下项目尚缺可验证的完整语音证据，保留原视频入口：`BV1RywNeNEry`、`BV1pC4y1P7dR`、`BV1h8DYBzErB`。访问限制或不匹配媒体不会被绕过。

## 省空间与公开范围

优先使用现有笔记和字幕。缺字幕时临时取得音频，复用本地 GPU 转写模型，结束后删除该次临时音频。截图通过远程定位取得，避免保存完整视频。已有归档不受影响。

公开内容只有选题目录、学习稿、经查看的截图、阅读器和字体许可。完整收藏列表、账号信息、Cookie、求职资料、私人路径、逐字稿与运行日志留在被忽略的本地目录。

本次发布站点约 34 MiB，大部分是既有阅读字体与复用图片；新内容没有新增模型或完整视频。证据采集设 2 GiB 空间上限及 5 GiB 剩余空间保护，发布包设 1 GiB 上限。所有可控缓存和临时文件位于项目目录，采集器拒绝在 Windows 系统盘项目中运行。

## 维护入口

`catalog.json` 是选题表；`lessons/*.md` 是新稿；`assets/frames.json` 记录已查看的原帧；HTML 为已构建的阅读副本。复用文章继续以仓库 `notes/` 为来源。

本地重新渲染：`python -B scripts/build_course.py --stage`。需要项目现有的 Markdown、Bleach 与 MathML 依赖。发布端仅运行 `--stage-only`，使用 Python 标准库把明确允许的文件放到 Pages 包中，私有证据不参与部署。详细命令见项目 `DEVELOPMENT.md`。
