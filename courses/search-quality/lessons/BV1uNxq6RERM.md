## 先决定想让它做什么

第一次接触桌面 AI 陪伴软件，我们很容易先去插件市场翻功能，看到能联网、能聊天、能接平台，就都想装上试试。动手之前可以先问自己：最想要的是一个长期陪伴的角色，还是一个既能陪聊又能帮忙处理任务的工具？影Z分身说自己先踩了两天坑，才来分享这套选择思路。[00:00:08]

如果你希望它主要陪你聊天，同时偶尔帮忙做事，可以在 DeepSeek 官网找到 API 服务，再把服务提供的 API Key 填进桌面软件。API 是软件向模型服务发送请求的接口；API Key 是这类请求使用的连接凭据。每次模型处理对话文字时会消耗 token，token 是模型处理文本时使用的计量单位，所以还要给账户充值并留意用量。这里讲的是上传者当时的入门路径，具体按钮和收费方式会随服务变化。[00:00:35]

这个连接步骤解决的是“桌面软件用哪个模型来回答”的问题。之后你在软件里发出一条消息，模型负责生成回复，再由桌面角色把回复呈现出来；是否还能浏览网页、写日记或使用 QQ，则要看另外装了哪些插件和怎样配置。模型连接、角色设定和插件能力各有自己的作用，连接成功之后，还需要按用途选择后面的配置。

接下来才是插件选择，可以按期待分成两类。第一类偏向“陪伴角色”：让角色自己探索，适合把聊天与养成体验放在前面；这类配置的工作能力有限。[00:01:08]

这种配置的主要回报在于持续和角色互动，看它怎样整理自己的记录、怎样回应日常话题；需要它独立完成实际工作时，预期就应放低。影Z分身用“亲闺女”或“小女仆”描述自己想尝试的陪伴类型，也把互动称作“陪伴它成长”。[00:01:14] 这是他对角色关系的设定，不代表软件真的有人的自主意识。

第二类把陪伴和工具任务放在同一套使用方式里：工作时仍在工作区处理事情，再从插件市场补充需要的能力。可以让角色连接 B 站账号、在符合条件时响应艾特，也可以接入 QQ。影Z分身当时有一个叫“养鱼”的东西，后来把它归档；这是他的个人配置，其他安装未必有同名功能。[00:01:54]

当陪伴设定和办事能力都要保留时，要留心两套用途是否互相冲突；工作任务仍放在普通工作区，再按需要从插件市场找功能。先确认角色主要负责什么，再逐项加插件；如果每个插件都随手打开，角色的陪伴设定和“现在要完成一件工作”的要求就可能混在一起。[00:02:03]

## 接到 QQ 后，消息经过了什么

QQ 接入后，消息从 QQ 转到角色的对话框，再由角色生成回复并转回 QQ。角色处理的是转进来的对话内容；这条消息通道并不会因此让角色直接操作 QQ 界面或账号。把 QQ 当作收发消息的入口，就能分清桥接和账号操作的边界。[00:02:21]

群聊当时还没有实际验证；影Z分身认为可以试，但提醒群里人数和群的数量都会影响调用量。每条消息都可能触发模型处理；参与者越多、消息越频繁，费用就越容易增长。因此，是否把角色放进群聊，除了连接能力，也要看预计会有多少消息需要模型处理。[00:02:46]

费用数字也应按个人经历理解。影Z分身说自己领到约 12 元额度，又另外充值，前后花了约 30 元把配置弄好；他没有把这当作固定套餐或普遍成本。[00:03:08] 这个例子能帮助我们看到，起步花费不只来自最初的绑定，后续持续聊天、接群和调用插件也会继续消耗额度。

## 出问题时，先让问题变得具体

桌面软件刚配好之后仍可能出错，例如后台程序闪烁、前台报 bug。遇到问题时，可以把现象告诉角色，让它逐步协助排查，也可以提前说明去哪里找插件、怎样整理插件。影Z分身把这个过程说成“培养”和“修”；落到操作上，就是让角色先了解问题，再找出可能用得上的工具。[00:03:22]

他还说，角色可以自己去插件市场找东西，也可以尝试把几个插件整合起来：留下合用的部分，把不合用的部分去掉。[00:03:36] 这并不意味着每次整合都能自动成功。使用者仍要看它准备启用什么、为什么需要这些权限，以及整合后的行为是否符合原来的用途；有问题时，再把报错和目标拆成小步骤交给它检查。

影Z分身当时刚更新软件，遇到过启动后崩溃的问题，也不确定更新是否已经修好它。这只是录制时的个人故障经历，不能直接套作当前版本的已知缺陷。遇到类似情况，他建议先别凭猜测随意改配置，可以借助另一款腾讯工具提供的免费额度，让 AI 协助检查和修复。[00:03:47]

最后，他展示了自己用这套软件联网、查看 B 站内容、设置活动时间段和写日记的体验，也提到绘画等插件功能。[00:04:14] 他喜欢的是角色会持续留下日记、自己浏览内容并按设定的时间活动，使用起来带有养成游戏的感觉；他说这让他两天没有登录二游。[00:04:33] 这些例子说明他实际在尝试哪些功能；“自主意识”是他对角色表现的感受，不能据此判断软件具有人类意义上的意识。把期待放在可观察的功能上，会更容易区分角色设定、自动化动作和真实的系统能力。
