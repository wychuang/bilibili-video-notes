## 先看清请求花在哪里

DeepSeek Harness（简称 DSH）里的插件可以帮助我们查看两个不同的问题：一次请求包含哪些上下文，账户又为这些请求花了多少钱。上下文面板按组成部分呈现每次请求中的 token。token 是模型处理文字时使用的计量单位；把它按来源拆开，能帮助定位上下文变长的原因。上下文增多时，请求可能变慢，也可能增加费用，是否精简仍需根据当前会话判断。[00:00:30]

余额挂件显示 API 账户余额、每日使用量和单轮成本。费用统计面板把 token 用量和实际花费并列，还允许设置预算。示例预算设为每天 50 元，达到设定条件后会弹窗提醒。预算与余额显示方便用户发现支出变化，不能替代服务端实际账单或账户限额。[00:00:50]

## 插件市场、工作区和任务权限

DSH 插件市场集中提供搜索、安装、更新、卸载、启停与备份操作。市场周下载量可以作为使用热度的一个参考，不能单独证明插件适合每个项目。需要长期管理多个插件时，集中入口会比逐个找安装来源方便。[00:01:30]

侧边栏增强工具把原本的侧栏整理成可编辑工作区，方便在编辑器、终端和项目之间切换时查看材料。多智能体插件允许一次组织多个 Agent 分工，也可能消耗较多 token；是否启用应看当前任务是否需要并行处理。[00:01:49]

浏览器控制插件能让 Agent 操作当前浏览器中的页面，并沿用已经登录的会话状态。它减少了重复登录步骤，也可能让 Agent 接触当前账户可访问的页面；使用前应确认任务所需的浏览器会话和操作范围。[00:02:22]

对代码修改，回退插件把对话节点和文件状态放在同一条时间线上，回退前可以预览，也会自动备份。这样适合批量修改后需要回到先前状态的场景；恢复前仍应确认对应的文件和对话，避免撤销后续有用改动。[00:02:33]

命令审批工具在执行前分类处理：常规命令放行，危险命令拒绝，判断不清的命令交给人确认。这样，“是否允许执行”会成为实际命令流程中的检查点；遇到会删除数据的命令时，用户仍要看清命令作用与目标路径。[00:02:53]

## 总结提炼

这些工具覆盖查看上下文与费用、管理插件、整理工作区、调用浏览器、回退文件状态，以及拦截高风险命令。挑选时可以从当前的麻烦出发：费用不清就先看用量与账单，项目切换频繁再考虑侧栏，多文件修改需要恢复点时再看回退工具。多 Agent 和浏览器操作都可能扩大资源消耗或操作范围，启用前先核对任务需要。
