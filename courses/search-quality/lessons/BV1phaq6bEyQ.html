如何比较 AI Agent：看同一任务、交互和总成本

原标题：自费实测！这堆 AI Agent，到底哪个值得你用？【Agent大横评】
UP 主：三颗门牙X
时长：16 分 38 秒
链接：https://www.bilibili.com/video/BV1phaq6bEyQ/
阅读强度：标准

同样叫 AI Agent，生成文件后能不能编辑、能不能接入工作系统、一个任务花多少钱，都可能影响体验。一次个人横评用相同素材、网页动画和 3D 看房等任务观察差异。以下结果对应录制时的产品、配置、题目和个人评价；模型、功能与价格会变化，单次测试也无法推出普遍排名。

先给相同材料，再检查结果

第一组任务使用同一份 AI 录音笔资料，分别制作演示文稿、Excel 报价表和 HTML 首页。测试者认为多数结果接近；一个值得注意的细节是，所测 Codex 生成的页面主动考虑了手机适配。这里同样需要逐项核对报价数据、页面内容和响应式效果，外观接近并不意味着事实和计算都正确。

接着用 HTML 和 SVG 制作一只骑自行车的鹈鹕。测试者偏好 Codex 使用 GPT-6 Astra 生成的风格统一的作品，也注意到千问的结果加入了切换场景的按钮；这属于他对这次创作任务的个人观感。

模型相同，运行框架也可能改变结果

可以把模型想成负责理解和生成的一部分，把 harness 理解为围绕模型组织上下文、工具调用和执行流程的框架。两者组合以后才构成这次讨论的 agent 使用环境。框架会影响模型看到的信息、能调用的工具以及迭代次数。

测试者随后把 DeepSeek V4 Pro 接到四种环境，先做选择一天活动的网页，再做 3D 看房网页。以下是他对后一个任务的观察与当次花费：

环境 录制时的结果观察 花费
WorkBuddy 入口难找，前后移动方向相反 2.08 元
Claude Code 整体尚可，天花板缺失 3.50 元
DeepSeek Harness 房间处理较好，有地板纹理 2.00 元
Codex 完成度和细节获较高评价 7.26 元

这些数字是当次任务的花费，受运行轮次、上下文、计费与配置影响。它们说明比较时应同时看结果与成本，不能替代多次重复测试，也不能据此推断某个环境在所有任务上都更好。

办公体验：文件能否继续修改

实际办公里，生成第一版只是开始。测试者关注文档预览区能否选中内容并交给 AI 修改、是否要跳转外部软件，以及工作项目能否配置连接器和邀请同事。已有的组织文档、日程与待办如果能在授权范围内作为上下文，可以减少手动搬运；具体联动和权限要核对所用版本。

视频中，测试者在 WorkBuddy 里没能让 agent 自动新建另一项对话，Codex 则展示了分派和查看任务的操作。这是其当时的使用观察，功能可能变化。

原型要点得动，才便于讨论流程

另一个比较使用 Kimi K3 和同一段提示词制作语音记账应用的 HTML 原型，要求有记账、统计、历史和设置四个页面，并可以点击。测试者看到 WorkBuddy 的结果主要呈现视觉效果，按钮未能交互；Kimi Agent 的结果可以点击，用来传达按钮行为更方便。

这个例子把评价标准说具体了：如果目的只是讨论颜色和布局，静态画面可能够用；如果要讨论点击后去哪一页、输入如何反馈，就要逐一测试交互。可点击原型仍然只是演示，不能据此认定语音识别、数据保存或正式应用已经实现。

测试者也展示了 GLM 的 Agent 生成的交互式 3D 太阳系，观察旋转、缩放和选择行星的效果；他同时说该环境生成的办公文件在当次测试中不便直接编辑。同一个产品的表现应按任务拆开看。

扩展、费用与长期使用

部分工具支持插件、不同访问权限或多智能体模式，带来更多组合方式，也增加配置与检查工作。自动审查是否询问、可读取和修改哪些文件，要以实际授权与设置为准。会员档位、调用额度和 API 价格可能调整，购买前应查看当时的产品说明。

另一类功能会保存偏好、项目习惯或历史记录，让后续任务能够复用；使用前可了解记录保存在哪里、如何查看和更正，以及哪些内容适合交给工具处理。

总结提炼

这次横评最有用的观察方法是把抽象评价落到实际动作：同一资料能否生成准确文件，网页在手机上能否使用，原型按钮能否点击，任务完成总共花了多少。换成自己的材料、明确成功标准并重复检查，比记住某次排名更能帮助选择。

时间导航

办公和动画任务 ；同模型不同环境 ；3D 看房结果 ；交互原型 ；记忆与长期使用 。

复习

你的任务最需要生成质量、可编辑性还是系统连接？如果两次结果价格不同，还需要记录哪些条件才能比较？
