设计技能、插件和模型各自做什么

Oil UI 是上传者此前开源的一套设计 skill，用来给 AI 提供网页设计和实现时可参考的规范。他在这套 skill 的基础上做了面向 DeepSeek Harness 的插件，希望把设计指引、页面检查工具和子 agent 提示词更直接地接入工作流程。

这期主要展示他用 DeepSeek V4.1 Flash 生成的网页案例，并解释为什么把 Oil UI 做成 Harness 插件。上传者认为，新版本在审美和读取 skill 规范方面进步明显；这是他的实际使用感受，视频用自己挑选的案例来说明。

几个设计案例展示了什么

落地页案例使用了上传者提供的图片生成工具，让页面设计包含 Oil UI 中的配图要求。其他展示包括日历式页面、用 SVG 呈现宽高与指标的页面，以及带材质切换和价格信息的椅子 B2B 网站。上传者特别提到页面里的渐变、图片选择和克制的颜色处理。

移动端案例是一份三页的音乐年度报告：页面切换时有动画，数字会滚动，图表也带动画。另一个 AI agent 主题的落地页刻意用了衬线字体和偏人文的视觉方向；下滑时，左侧内容吸顶，右侧继续滚动，并在后续模块里绘制网格动画。

他还展示了椅子网站的三种风格探索结果，以及一个青铜钟表主题的 B2B 网站。钟表页使用透明背景的生成图片、材质切换、参数示意图、网上搜索到的配图、表单和小票式视觉元素。页面中的生成图片和搜索配图都由上传者提供的工具辅助制作。

插件把哪些步骤接进 Harness

插件提供三个斜杠指令：oil-ui-explore 用来探索三种不同的页面设计方向，oil-ui-review 会截图并检查 UI/UX，oil-ui-status 用来查看 Oil UI 版本、本地 Pro 检测和图像生成能力。多个探索方案也能放进 Harness 侧边栏比较。选定方向后，网页仍要经过多轮修改；检查页面时，原有 skill 通过脚本提供截图、动画排查和元素位置等能力。插件将这些操作包装为 Harness 可直接调用的工具，减少 agent 先查脚本参数的步骤。

另一项集成是启动子 agent 时注入提示词。通用 skill 要兼顾不同 agent，主 agent 往往需要先读一份如何组织子 agent 提示词的规范；插件可以把相应提示直接带入子 agent 流程。上传者希望这样减少主 agent 需要处理的说明文本和 token 用量。

安装与版本边界

安装时，把插件仓库交给 DeepSeek Harness，请它安装；Oil UI 网站也增加了跳转到插件仓库的入口。插件复用 Oil UI skill，已购买 Pro 版本的用户可以沿用 Pro skill。
