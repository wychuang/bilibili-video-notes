# DSH 插件演示：上下文、工作区与操作权限

> **来源**：天才依山尽，《【拒绝废话】用DSH必须下载的八个插件》，2:55，https://www.bilibili.com/video/BV1GJnZ6MEFw/  
> **阅读强度**：quick

DeepSeek Harness（DSH）周围可以接入不同用途的工具：有的压缩长对话，有的让请求花费更容易查看，还有的把图像、聊天渠道或电脑操作接入现有工作流。逐个看它们处理的问题，比按下载热度判断是否需要安装更有帮助。

长对话不断累积时，模型要处理的上下文也会变长。上下文是模型当前能看到的对话、指令和工具结果；token 是模型处理文字时使用的计量单位。压缩工具会把部分旧内容整理成较短的信息，让后续请求继续沿用先前背景。推荐理由包括节省费用和减少幻觉；具体效果会受模型、压缩方式和任务影响，不能当作对所有情况的保证。[00:00:03]

插件市场提供搜索和安装入口。费用挂件可以显示一轮任务花费；桌面宠物则提供屏幕上的陪伴。侧栏工作台增加文件、Markdown 预览、终端和 Git 等入口，也允许其他插件注册自己的标签页。多个工具在这里集中出现，适合需要在编辑器项目、终端和插件之间切换的工作场景。[00:00:14]

如果一段对话进行到一半后回答质量下降，可以查看上下文组成面板。它把人格设定、记忆、工具返回结果等来源分开呈现，并显示何时压缩过上下文、压掉了哪些内容。这样能帮助我们检查模型当前看到的材料是否被无关内容占满，或重要信息是否已经不在上下文里。[00:01:00]

图像桥接工具处理模型无法直接读取图片的情况。当时使用的 DeepSeek 模型被描述为纯文本模型，不能直接接收图片；工具会把粘贴的图像转换为结构化文字，列出图中文字、版面和排列，再交给模型。图片改成文字后会丢失部分视觉细节，因此任务仍需检查文字描述有没有保留真正重要的内容。[00:01:26]

聊天渠道连接工具把手机消息转到电脑上的 DSH。出门时可以从微信、飞书、钉钉、QQ、Telegram、Slack、Discord、WhatsApp 等渠道发送任务，再从聊天窗口接收电脑端处理结果。具体可连接哪些渠道要看工具当前支持范围；电脑仍会在本机执行收到的任务。[00:01:51]

命令审批工具在命令运行前检查操作。删除文件、改动 Git 仓库或读取 SSH 密钥都可能带来风险；命令被判断为危险时，工具会先拦截并等待用户确认。检查点放在执行前，能给用户一次看清命令和目标位置的机会；遇到有破坏性的操作，仍需自己理解即将运行的内容。[00:02:18]

## 总结提炼

这些工具覆盖长对话压缩、费用查看、插件安装、工作区整理、上下文检查、图像转文字、手机远程发令和命令审批。选择时可以从当前困难出发：上下文太长时关注压缩，回答质量变化时检查上下文组成，需要远程发任务时再看聊天连接。图像描述与电脑命令都有各自的能力边界，实际使用时应核对任务需要的信息和操作范围。
