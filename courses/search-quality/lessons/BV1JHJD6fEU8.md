# TextFold：把长文折叠成可展开的阅读层级

> 来源：**降低认知负担，让文字折叠｜科研工具第二弹！TextFold 开发者实操**｜UP 主：Chatchan｜时长：04:57｜[Bilibili 原视频](https://www.bilibili.com/video/BV1JHJD6fEU8/)｜阅读强度：quick

读论文或长网页时，我们常在两种困难间来回：一开始逐句读，容易被细节淹没；只看标题或摘要，又可能漏掉论据怎样支撑结论。TextFold 想在两者之间提供一种阅读方式：先把原文压成几个层级的概览，需要时再展开细节，读者可以在概览与原文之间来回对照。[00:00:05]

## 从一篇文章开始，先调阅读颗粒度

把文章链接输入 TextFold，页面会生成五个折叠层级。拖动层级控制后，内容会从较完整的段落逐步收束成更短的概览，最后呈现类似地图的整体结构。先看概览，可以判断文章大致在讲什么；发现一个段落和当前问题有关，再展开它，并对照原文继续读。折叠的作用在于控制屏幕上同时出现的信息量，读者仍可以回到完整上下文查看细节。[00:00:13]

产品演示列出的输入包括 Office 文件、PDF、HTML、纯文本、Markdown，以及维基百科和 GitHub 等网页来源。导入后的文章可以按主题查看主张、缺口、方法、设置和结果等信息。对科研论文来说，这些标签能帮助我们迅速定位文章的论证部件：作者主张什么、指出了什么尚未解决的问题、采用什么方法、实验怎样设置、最后报告了什么结果。标签是浏览线索，判断结论是否可靠仍要回到原文的方法、数据和限定条件。[00:00:59]

## 让提问、笔记和原文留在同一份材料里

阅读时可以对段落做高亮、记笔记，也可以针对全文提问，例如“这篇文章的核心证据是什么”。TextFold 会调用大语言模型生成回答，并列出对应上下文，方便读者回到文章里核对。操作顺序很简单：先导入文献，浏览折叠后的结构；遇到需要确认的论点时提问，再查看回答所指向的原文片段。模型给出的回答仍需和原文对照，尤其要核查证据是否真的支持结论、回答有没有遗漏限定语。[00:01:53]

笔记、问答和原文可以选择保存为一个 HTML 文件，之后带走阅读。开发者还演示了连接自己的 Zotero 文献库，再把文献内容导入 TextFold 处理。演示展示的是这一套工具的使用场景；可用格式、连接方式和导出选项仍应以实际安装的版本为准。[00:02:38][00:04:13]

## 为什么要折叠：阅读量增加不等于理解同步增加

开发者介绍，做这个工具的起点是读到一篇讨论生成式 AI“认知债务”的文章：AI 能以很低成本生成大量文字，但读者吸收和理解内容的速度未必同步提升。我们可能读了更多页面，却记不住论证，也说不清证据和结论怎样相连。TextFold 借用了超文本里的 stretch text 思路，让读者按需要展开内容，在不同细节层级间移动。它提供的是阅读界面的组织方法；折叠后的摘要和模型回答不能替我们完成理解，最终判断仍需要回到原文。[00:03:01]

## 总结提炼

- 输入文章后，用五级折叠先浏览整体，再按需要展开段落，控制屏幕上的阅读颗粒度。
- 用主题、主张、缺口、方法、设置和结果等标签快速定位论文的论证部件。
- 在同一份材料里高亮、记笔记、向全文提问，并把笔记、回答和原文保存为 HTML；演示还展示了 Zotero 导入流程。
- 先看结构、再按问题展开细节，适合快速判断长文重点并回到对应段落继续读。
