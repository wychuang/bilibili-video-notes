## 先让 Bot 能调用模型

部署一条桌面 AI 鱼到 QQ，先要让桌面助手、Bot 平台和 QQ 之间接上消息，再决定角色怎样说话。IceTang_冰糖开头提醒，这些操作和 Bot 调用模型都会消耗 token；token 是模型处理文字时使用的计量单位，额度不足时就需要为模型服务准备可用额度。[00:00:00]

第一步是在浏览器找到 DeepSeek 的创作者平台，下载桌面助手并安装、登录。之后打开 DeepSeek 开放平台，创建 API Key 并保存好。API Key 是桌面助手调用模型服务时使用的凭据；后续对话会按输入、输出文本消耗 token，两者的作用不同。[00:00:19]

接下来把部署任务交给桌面助手：让它安装 Bot 项目和 QQ 桥接组件，组成一个能在 QQ 收发消息的机器人。安装过程要等一段时间，助手可能会要求不同的权限；完成后会给出两个访问地址供登录。如果没有收到登录密码，可以继续向助手询问。[00:01:08] 这一步做完，先进入 Bot 的模型设置，新增 DeepSeek 服务，把刚保存的 API Key 填入，再获取可用模型列表、选择一个对话模型并保存。[00:02:13]

模型服务配好后，还要在第二项配置中选择 OneBot v11。然后进入 QQ 桥接程序的“进程注入”页面，选中已经登录、专门准备给 Bot 使用的 QQ 账号。[00:02:52] 这会把 Bot 的消息能力接到该 QQ 会话里；配置完成后，鱼就可以先用默认人格与你对话。[00:03:17]

## 再调整人格和不同会话的说话方式

默认人格只是开始。进入人格设定后，可以新增一份角色设定；如果还没有提示词，就把想要的性格和表达方式描述给桌面助手，让它生成一版，再根据效果继续修改。[00:03:55] 人格提示词负责约束角色如何回应，修改时可以对照自己期待的语气，而不必一开始就手写完整文本。

要设默认人格，可以在配置文件中打开 AI 的人格选项并选择对应设定。若不同会话想使用不同角色，则在“自定义规则”中新增规则，先选会话，再选人格，最后保存。[00:04:51] 这样，默认设定负责一般聊天，规则可以把特定会话交给另一套人格。

## 表情包和消息节奏

如果希望鱼能发送表情包，可以从插件页安装表情包管理器，再刷新 Bot 页面，从插件入口进入资源广场挑选并下载表情包。下载可能比较慢，可以放在后台进行；如果直接安装不顺，也可以把安装任务交给桌面助手处理。[00:05:38]

扩展设置里还有几项会改变消息呈现方式。分段回复会把一段回答按配置的分隔符拆成几条消息，并按间隔逐条发送；示例把间隔设为 1 至 2 秒。分段用的正则表达式决定在哪里切开，内容过滤规则则决定切开后移除什么，例如删掉消息末尾不需要的逗号。[00:07:38]

群聊可以读取近期消息并把它们注入上下文，让鱼知道正在聊什么；最大消息数可以调低，带进上下文的文字少一些，token 消耗也会减少。再打开主动回复，并把对应群号加入白名单，鱼才会在该群按设置的概率主动接话。作者建议不要把每条消息的插话概率设得太高，以免回应过于频繁。[00:08:45]

最后，插件还可以继续扩展。IceTang_冰糖举例说，统计消耗、添加或删除好友、退群，以及写日记等功能，都是她向桌面助手描述需求后得到的扩展。[00:09:42] 这些是她自己的配置实例，功能是否可用仍取决于当前插件与账号连接情况。

## 总结提炼

接入过程依次完成模型 API、Bot 模型配置、OneBot v11 与 QQ 桥接，再设置人格、表情包和可选的消息节奏；群聊主动回复还需要设置上下文数量、回复概率和白名单群号。
