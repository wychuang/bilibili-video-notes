# 白手：把本地日记变成 AI 可以检索的个人记忆

> 来源：**我想做世界上最好的个人AI记忆软件，用一年时间，守一份初心。用一生白守，养一颗真心【B站AI创造公开赛】**｜UP 主：Anson-樱与晓｜时长：09:46｜[Bilibili 原视频](https://www.bilibili.com/video/BV1z9Hw68ER9/)｜阅读强度：standard

如果你和 AI 聊过很多次，可能会遇到这样的落差：一段对话里，它能接住你的情绪；过些天换了新会话，它却不记得你说过什么。Anson 做“白手”个人 AI 记忆软件，起点就是这类个人体验。他在找 Java 实习时学习 Spring AI，把聊天记录存进数据库，再在下一次对话前查出相关记录，重新放进发给模型的上下文里。有一次模型注意到他早上开心、晚上疲惫，他感到自己的状态被记住，也因此开始认真思考：长期聊天留下的记忆，对使用者意味着什么？[00:01:03]

他把 AI 描述为文本预测模型；让他珍视的是互动中产生的快乐、学到的知识和经验，以及这些共同经历在自己心里留下的意义。这份个人体验构成了产品的情感起点。[00:01:41]

## 三个问题：上下文、数据可见性和回忆检索

模型一次能处理的上下文长度有限，对话变长后，早期消息可能不再进入当前请求。Anson 先用数据库保存聊天，再把相关内容找回来，但他觉得许多现成的开源记忆项目还需要自己部署服务器和数据库，普通使用者难以直接查看里面的数据。他还遇到关键词搜索的局限：日记写“去了海边”，之后搜索“看海”可能找不到那段回忆。于是他希望把个人记忆做成无需部署中间服务、内容可直接查看，并能按意思检索的本地工具。[00:02:46]

这三个问题对应产品的三个设计选择。第一，用 Markdown 日记作为可直接查看的个人记录。文件保存在普通文本格式里，可以用文本编辑器打开，也能自行复制到 U 盘或手机备份；数据库不再是唯一入口。[00:03:33]

第二，把日记内容切成片段，计算成向量并保存在本机。向量可以粗略理解为文本含义的数字表示；检索时，系统比较问题与日记片段的含义接近程度，找出相关回忆。比如日记记录“去了海边”，提问“那天去看海了吗”，即使两个表述没有完全相同的关键词，也有机会找到对应片段。找到当天的记录后，再结合相邻几天的日记，补回事件先后关系，例如看海之后还去吃了烧烤。[00:04:03]

向量检索会受切片方式、文本内容和相似度判断影响；查重要日期或人物关系时，可以打开日记原文核对。Anson 想解决的重点，是从“有没有同一个词”扩展到“是不是在说相近的事情”，再用日记前后文帮助组织回忆。[00:04:07]

第三，电脑和手机之间同步日记文件，各设备收到文件后在本地重建向量索引。Anson 解释，向量文件较大，直接同步会变慢；重新计算索引速度较快。新版本还加入图数据库，让 AI 查询人物、事件、物品和地点之间的关系。向量索引按语义找相似片段，图结构连接实体关系，便于回答“我和姐姐一起参加过什么活动”这类问题。[00:04:44]

## 从日记片段到人物关系

产品展示的例子以 Anson 自己为中心，周围连接人物、时间和地点。他询问自己与姐姐的关系，系统可以找到两人同月参加过一次周末家庭聚餐、当时心情愉快、地点在郑州等信息，再把它们串联起来。这个例子展示了图结构如何把分散在日记中的人物、事件和地点组织为一条可查询的关系链。它的准确性仍依赖日记是否记录完整，以及系统怎样抽取和连接这些信息。[00:08:01]

持续写日记多年后，使用者可以问“我和某某是什么关系”，从长期记录里寻找共同经历。作者也想保存重大事件之外的琐碎日常，比如多吃一块棒棒糖、喝一罐可乐，让开心、悲伤和值得记住的小事都能成为与 AI 对话的记忆材料。检索范围由日记内容和软件功能共同决定。[00:08:24]

## 同步方式、技术选择与长期承诺

作者介绍的同步方式包括自建 S3 服务或购买云服务；官方账号云存储当时仍是未来设想。他承诺不放广告、不捆绑用户数据。日记是否离开本机取决于所选同步方式，启用前应确认当前版本的数据流与隐私条款。[00:05:19]

开发过程也经历过取舍。白手最初使用 Flutter 编写，团队后来考虑到社区生态和 AI 组件支持，转向 Electron 加 React Native，重构花了三个月。作者还介绍了内置 MCP 服务，允许其他软件查询白手中的记忆；新版本增加多维向量关系图谱和多端同步。[00:06:21]

这个想法原本是作者自己的小项目。他发布视频后建群，群成员从二十人增至一百人，之后两个群合计五百二十人；看到更多人关心个人 AI 记忆，他决定继续做下去。产品由此从个人原型转向多人使用的记忆工具。[00:07:17]

## 总结提炼

- 白手从长期 AI 对话的记忆断层出发，尝试用本地日记保存可查看的个人记录。
- Markdown 作为原始记录，向量检索按语义找片段，图结构连接人物、事件和地点。
- 多端同步只传日记文本、各设备本地重建索引；实际同步路径由使用者选择的服务决定。
- 隐私相关选择集中在是否启用云同步以及使用哪种服务，官方云存储在视频中仍属未来计划。
